## 1. 工程与页面

原工程使用 Electron 12、Vue 2、Vue Router 3、Vue CLI 4、Less；主进程负责窗口、系统能力和下载，渲染进程直接请求 Wallhaven API，通过 preload 暴露的 IPC 与 electron-store 读写本地数据。

| 入口 | 功能 | 源码状态 | 依据 |

| 推荐 | 最近更新、热榜、收藏榜、查看榜 | 已有代码 | `layout/pages/home/index.vue` |
| 壁纸 | 搜索、筛选、分页图片列表 | 已有代码 | `layout/pages/wallpaper/` |

页面通过 hash 路由导航，使用 `keep-alive` 保留页面实例，导航栏有返回入口。标题栏的刷新按钮调用当前页面的 `onRefresh`。

## 2. 推荐与在线搜索

### 推荐

- 四个独立图片分组：最近更新 `date_added`、热榜 `hot`、收藏榜 `favorites`、查看榜 `views`。
- 每组请求第一页，固定 `order=desc&categories=111&purity=110`；推荐请求没有附加配置中的 API Key。
- 图片横向展示，左右按钮滚动；图片可预览、收藏、下载、设为壁纸。
- 推荐页的刷新会清空并重新请求各组。

依据：`layout/pages/home/index.vue`、`layout/components/image/img-list-horizontal.vue`。

### 搜索筛选

| 条件 | 原项目提供的选项或行为 |
| --- | --- |
| 关键词 | `q`，通过搜索按钮提交 |
| 分类 | 全部 `111`、通用 `100`、动漫 `010`、人物 `001`，单选 |
| 内容等级 | SFW、Sketchy、NSFW，可组合；编码为三位 `purity`；未选择时回落到 SFW |
| 分辨率 | “至少”对应 `atleast`，单选；“相等”对应 `resolutions`，多选；预设覆盖 1280×720 至 3840×3072 等尺寸 |
| 宽高比 | 横屏、竖屏、16:9、16:10、21:9、32:9、48:9、9:16、10:16、9:18、1:1、3:2、4:3、5:4，可多选 |
| 颜色 | 预设颜色或不限，单选 |
| 排序字段 | 最新、热度、查看数、收藏数、随机、排行榜 |
| 排序方向 | 升序、降序 |
| 排行榜时间范围 | 近一天、三天、一周、一月、三月、半年、一年 |

- 默认条件：全部分类、SFW、最新、降序。
- 高级条件可展开／收起，点击搜索后收起。
- 列表接近底部时请求下一页，显示总命中数；首次成功请求后会再请求一页。
- 搜索请求读取 `appConfig.apiKey`，非空时追加到查询参数。
- 自定义宽高只有状态字段和参数拼接逻辑，模板中没有对应输入框。
- 筛选项变化没有自动发起搜索；该 watcher 已注释。壁纸页的刷新方法只重置条件，没有重新发起请求。

依据：`layout/pages/wallpaper/index.vue`、`layout/pages/wallpaper/search/search-area.vue`、`layout/pages/wallpaper/search/data.js`、`layout/libs/util.js`、`layout/libs/ajax.js`。

## 3. 图片列表与大图预览

- 图片卡片显示文件大小、分辨率、文件类型，提供收藏／取消收藏、下载和设置壁纸入口。
- 在线列表支持瀑布流与固定高度平铺，按容器宽度调整列数。
- 列表只渲染可见区域附近的图片，带骨架占位、滚动位置记录和重新布局动画；数据按壁纸 ID 去重。
- 推荐列表使用独立的横向布局；收藏列表固定使用平铺。
- 大图预览先显示缩略图，再获取原图 Blob；支持滚轮等比缩放、拖拽、还原居中、缩放百分比、关闭。
- 预览界面也提供收藏、下载和设为壁纸；图片加载失败会显示占位图／提示。

依据：`layout/components/image/img-list.vue`、`img-list-horizontal.vue`、`img-view.vue`、`img-plus.vue`、`minix.js`。

## 4. 本地收藏

- 按壁纸 ID 保存图片元数据，支持新增、移除与状态同步。
- “我的”页面读取本地收藏并展示图片；空收藏有提示。
- 收藏页面复用预览、下载和设置壁纸操作。
- 使用本地 `collections` store；仓库中没有账号登录和收藏云同步实现。

依据：`layout/main.js`、`layout/pages/collection.vue`、`src/main/lib/database.js`。

## 5. 下载中心

- 从列表或预览加入原图下载，同一个正在下载的 ID 不重复提交。
- 下载中心分为“下载中”和“已完成”；显示缩略图、尺寸、文件大小、进度、已下载字节和速度字段。
- 提供暂停、继续、取消；保存 URL 链、偏移、总长度、ETag、Last-Modified、开始时间等恢复信息，通过 Electron 的中断下载接口尝试断点恢复。
- 退出或子进程结束时有暂停任务、保留 `.temp` 临时文件的逻辑。
- 可选择下载目录；完成记录包含时间与本地路径，可以在文件管理器定位文件。
- 支持删除单条完成记录和清空完成记录；这两个操作不等于删除已下载的原图。
- 预览已取得 Blob 时另有一条直接保存路径；选择“设为壁纸”会在保存后调用系统壁纸能力。
- 常规下载完成时也可以根据任务标记自动设置壁纸，并向主窗口发送完成事件。

依据：`layout/pages/download.vue`、`layout/components/image/minix.js`、`layout/libs/send.js`、`src/main/lib/ipcMain.js`。

**尚未验收的下载行为：** 上述恢复代码不代表跨重启恢复已经可靠。退出时的已暂停分支引用了作用域外的 `cacheItem`；状态分支和页面移除记录也存在不一致，重写时需要重新定义状态机并验证，不沿用这些实现细节。速度字段按回调前后字节差计算，原实现没有按实际时间间隔折算。

## 6. 系统能力与应用设置

| 能力 | 源码中的行为 |
| --- | --- |
| 设置桌面壁纸 | 通过 Node `wallpaper` 包设置本地文件；本轮未验证各操作系统的实际效果 |
| 下载位置 | 首次使用系统下载目录；修改目录后写入设置并更新 Electron downloads 路径 |
| 开机启动 | 设置开关写入 `openAtLogin`，变化监听调用 `app.setLoginItemSettings` |
| 预览模式 | 设置窗口切换平铺／瀑布流；列表创建时读取该设置，没有实时订阅切换 |
| 主题 | 经典白、炫酷黑；保存 `theme` 并切换根元素 class，`public/index.html` 在启动时读取保存值 |
| 窗口 | 无边框主窗口、独立设置窗口；标题栏最小化、关闭隐藏；IPC 还有最大化切换和重启入口 |
| 托盘 | 打开主窗口、打开设置、退出；提示显示名称和版本号 |
| 单实例 | Electron 单实例锁；第二次启动时尝试恢复并聚焦主窗口 |
| 日志 | 展示随应用内置的版本更新日志 JSON，不是运行日志查看器 |
| 关于 | 应用介绍和图片来源／版权说明 |

依据：`src/main/index.js`、`src/main/lib/window.js`、`src/main/lib/ipcMain.js`、`public/config.html`、`public/index.html`、`layout/layouts/components/`。

## 7. 本地数据与接口边界

| 本地 store | 保存内容 |
| --- | --- |
| `collections` | 按 ID 保存的壁纸收藏元数据 |
| `downFiles` | 未完成下载的状态与恢复元数据 |
| `downDoneFiles` | 已结束下载的记录；代码也将部分失败记录放在这里 |
| `appConfig` | `previewMode=waterfall`、`downloadPath`、`openAtLogin=false`、`theme=dark`、`apiKey` |

远程请求入口为 `https://wallhaven.cc/api/v1/search`。搜索页和推荐页消费列表返回的图片信息，未发现单独的详情 API 调用。原图通过列表中的 `path` 获取。本轮没有请求 Wallhaven 服务，因此服务的当前参数限制、访问权限与可用性尚未确认。

`apiKey` 只有默认字段与搜索读取逻辑，设置窗口没有输入入口。桌面组件、自动定时换壁纸、动态壁纸、账号登录和云同步未找到业务实现。下载完成的系统通知函数虽存在，调用处已注释。

本次核对发现的下载页当前目录／修改入口和累计已下载／总大小已补齐，复用独立设置中的目录选择、验证与持久化。修改只影响之后的新任务，正在下载和暂停恢复的任务仍保留原目录。暂停时保留下载量并停止显示速度；没有任务时仍可修改目录。

原版最大化、重启只有内部 IPC 接口，未找到前端按钮；当前未接对应专用入口。API Key 原版也是保存字段加搜索读取、没有设置输入框；当前改为环境变量读取，不自动导入旧值。组件、定时换壁纸、动态壁纸、账号及云同步在原版未找到完整实现，不计为完整功能漏迁。推荐左右箭头、加载更多和命中总数文案按用户要求移除，不列为待恢复项。

当前推荐使用原版四组查询条件；搜索默认 SFW。筛选变化需点击搜索或回车提交；重置会实际重新搜索，修正旧版只重置不刷新的行为。分辨率增加了可用的自定义输入入口，支持预设最小尺寸或多选精确尺寸。首个搜索页成功后预取第二页，随后滚动接近底部自动加载，页尾显示加载动画；按用户要求移除加载更多按钮和命中总数文案。可见缩略图优先加载，附近图片后台预取，列表复用快照与布局；失败保留已展示结果并重试原页。推荐去掉左右翻页箭头，保留横向滚动。详情信息面板默认收起，点击信息按钮展示。切换页面保留筛选和结果，新搜索会取消并拒绝旧请求结果。

全量普通测试、MyGO 检查和 macOS ad-hoc 应用包构建通过；下载后台、图片、应用状态、存储与下载 UI 的专项 race 检查通过。下载集成测试使用本地 HTTP 服务验证暂停后重建控制器／下载器／存储再续传、原目标目录保持、原图缓存免重复 GET、删除历史保留原图；不将这些结果称为真实 Wallhaven 中断下载的实机验收。Windows／Linux amd64 整项目纯 Go 交叉编译通过，平台适配通过注入调用器测试，尚未在真实 Windows／Linux 桌面设置壁纸。Linux 未提供其他桌面或通用 Portal 后备。

此前已验证真实四组推荐、组合筛选、无结果、两页搜索及真实缩略图解码；原生交互和布局通过 MyGO Tester 检查，实际 macOS 进程已核对独立设置窗口、目录选择取消、内外圆角与第二次启动唤起，并确认 ad-hoc 签名。开机启动尚未进行注销／重新登录验收；受限内容的 API Key 访问尚未验收。此前全量 race 检查达到默认10分钟时限，超时处及其后最后一个缩略图用例单独在 race 下通过，不宣称全量 race 已通过。随机分页的上游 seed 行为限制与重现命令记录在 [README](../README.md)。

旧实现的 Windows 风格路径拼接、渲染进程直接访问网络／存储、关闭 Web 安全校验等做法不作为新架构的实现约束。MyGO 的依赖、分层和 UI 生命周期约定见 [架构说明](architecture.md)。
